Chapter 20 — Aldehydes and Ketones

Nucleophilic Addition Reactions ｜ 親核加成反應 ｜ 期末考重點
本章核心：親核劑攻擊 C=O 碳。所有反應都圍繞同一主題 — 用什麼當親核劑、酸/鹼條件、產物穩定性。
考試常出：機制（imine、acetal、Wittig）、產物預測（Wolff-Kishner vs Clemmensen vs Raney Ni）、合成路徑設計。
20.1 Introduction 介紹
羰基官能基（carbonyl group, C=O）是醛（aldehyde）與酮（ketone）的共通結構：
‧ Aldehyde（醛）：R–C(=O)–H，C=O 一邊接 H
‧ Ketone（酮）：R–C(=O)–R'，C=O 兩邊都接 C
常見天然羰基化合物：vanillin（香草醛）、cinnamaldehyde（肉桂醛）、(R)-carvone（薄荷酮）、benzaldehyde（苯甲醛）、progesterone（孕酮）、testosterone（睪固酮）、pyridoxal phosphate（PLP，活性 vit B₆）、hydrocortisone（氫化可體松）。
20.2 Nomenclature 命名規則

醛 Aldehyde

  • 母鏈字尾 -e → -al（如 butane → butanal）
  • 母鏈必須包含羰基碳（即使主鏈不是最長的也優先選含 CHO 的那條）
  • 羰基 C 永遠是 C1（不需寫位置號）
  • 羰基的編號優先於其他取代基

酮 Ketone

  • 母鏈字尾 -e → -one（如 butane → butanone）
  • 羰基 C 的位置號可寫在字首或後綴前，例如 3-heptanone = heptan-3-one
  • 編號讓羰基碳的位置號最小

20.4 Carbonyls as Electrophiles 親電性 + 親核加成

為什麼羰基碳是好親電劑？三個因素

  1. Resonance（共振）：C=O 有一個帶 C⁺ / O⁻ 的次要共振結構 → 羰基碳本身帶部分 δ⁺。
  2. Induction（誘導效應）：O 電負度高，把 C–O 鍵電子拉向 O → C 帶 δ⁺。
  3. Sterics（立體效應）：羰基 C 是 sp² 三角平面，比 sp³ 開放 → 親核劑容易上來攻擊（從約 107° 角度進攻 → Bürgi-Dunitz 角）。

醛 vs 酮 反應性比較

醛 > 酮（醛在親核加成反應中比酮反應性更高）
原因說明
Sterics（立體）醛 C=O 只有 1 個大取代基（另一邊是 H）；酮有 2 個。醛比較開放，過渡態能量較低
Electronics（電性）酮多一個烷基，烷基穩定 C 的 δ⁺（如同 2° 碳陽離子穩定）→ 酮的 C=O 沒醛那麼缺電 → 反應性差

親核加成的兩種條件

強親核劑（如 OH⁻、CN⁻、RMgX、H⁻）：
  1. Nu⁻ 攻擊 C=O 碳 → 四面體 alkoxide 中間體（O 帶負電）
  2. 溫和質子源（H₂O）質子化 O⁻ → 得到醇/加成產物
弱親核劑（如 H₂O、ROH）：需要酸催化
  1. H⁺ 質子化 C=O 的 O → 形成更活化的 oxocarbenium（C 更缺電）
  2. Nu 攻擊質子化的羰基
  3. 失質子 → 中性產物
記憶口訣：酸性條件下中間體只帶 中性 或 +1 電荷；鹼性下只帶 中性 或 −1。避免同時兩個正/負電荷的高能中間體。
20.5 Water + Acetal Formation 水加成 + 縮醛形成

水加成 → Hydrate（水合物）

C=O + H₂O ⇌ geminal diol（同碳二醇）= hydrate

羰基水合物比例原因
Acetone（丙酮）~0.1%2 個甲基 → 立體擠 + 電性穩定 C=O → 不易加水
Formaldehyde（甲醛）> 99.9%無取代基 → 無立體擋、無電性穩定 → 大量加水
Hexafluoroacetone（六氟丙酮）> 99.99%CF₃ 是強 EWG → C=O 更缺電 → 強驅力加水

Acetal Formation（縮醛形成）

反應產物
Aldehyde + 1 eq ROH（H⁺ 催化）Hemiacetal（半縮醛）R–CH(OH)(OR')
Hemiacetal + 1 eq ROHAcetal（縮醛）R–CH(OR')₂
Ketone + 1 eq ROHHemiketal（半縮酮）R₂C(OH)(OR')
Hemiketal + 1 eq ROHKetal（縮酮）R₂C(OR')₂
注意：Acetal 形成是可逆反應，且酸催化。要得 acetal → 移除水（Dean-Stark trap）；要逆轉 → 加水。

環狀縮醛（Cyclic Acetal）

  • 用二醇（diol）形成5 員或 6 員環的 cyclic acetal → 特別穩定
  • 常用：ethylene glycol（HOCH₂CH₂OH）→ 1,3-dioxolane（5 員環）
  • 或 1,3-propanediol → 1,3-dioxane（6 員環）

★ Acetal 當保護基（Protecting Group）

最重要的應用：保護醛/酮，讓它在後續反應中不被攻擊。
Acetal 在 鹼性 / 中性 / 親核 / 還原（LAH、NaBH₄）條件下都穩定，只在酸 + 水下水解回原 C=O。

典型流程：選擇性還原

例：把 ester 還原成醇，但分子上另有 ketone 不想被還原

  1. 用 HOCH₂CH₂OH / H⁺ + 移除水 → 把 ketone 保護成 acetal
  2. 用 LAH 還原 ester → 1° alcohol（acetal 不受影響）
  3. 用 H₃O⁺ 水解 → 還原 acetal 為 ketone，得到目標分子
Acetal 形成機制（酸催化，7 步）：
  1. C=O 被 H⁺ 質子化 → 增加 C 親電性
  2. ROH 攻擊 C → 形成 oxonium 中間體（+1 在 O–R 上）
  3. 失質子 → hemiacetal（中性）
  4. OH 被 H⁺ 質子化 → 變好的離去基（H₂O）
  5. H₂O 離開 → 形成新的 oxocarbenium（C=O⁺R）
  6. 第二顆 ROH 攻擊 → 新 oxonium
  7. 失質子 → acetal（中性）
20.6 Amines as Nucleophiles: Imine, Enamine, Wolff-Kishner

1° 胺 → Imine（亞胺）

RNH₂ + R'₂C=O → R'₂C=NR + H₂O（也叫 Schiff base）

機制（酸催化，6 步）：
  1. 胺攻擊 C=O → 四面體 N⁺ alkoxide
  2. 質子轉移：N 給 H⁺ 給 O
  3. 得 carbinolamine（α-胺基醇中性中間體）
  4. OH 被 H⁺ 質子化 → 變 H₂O 離去基
  5. H₂O 離開（E1-like）→ iminium ion（C=N⁺）
  6. 從 N 失質子 → 中性 imine（C=N–R）

2° 胺 → Enamine（烯胺）

R₂NH + R'₂C=O → R'-CR=CR₂-NR₂ + H₂O（烯 + 胺 = unsaturated amine）

機制：跟 imine 前 5 步完全一樣，到 iminium ion 階段。差別在最後一步：
  • 1° 胺：iminium 的 N 上有 H 可失去 → 形成 C=N 雙鍵（imine）
  • 2° 胺：iminium 的 N 上沒有 H → 改從鄰近 α-碳失質子 → 形成 C=C 雙鍵 + N 還在側邊（enamine）
最佳反應 pH ≈ 4-5：太酸 → 胺被質子化失活；太鹼 → 沒酸把 OH 變成離去基。

★ Wolff-Kishner Reduction

把 C=O 完全還原成 CH₂（醛/酮 → 烷類）。
條件：H₂N-NH₂（hydrazine）/ KOH / heat（強鹼，適合不耐酸的基質）
步驟：
  1. 羰基 + H₂NNH₂（酸催化 imine 機制）→ hydrazone（C=N-NH₂）
  2. KOH / heat → 從 NH 失質子 → 共振穩定的 dianion
  3. 從 H₂O 抓 H 到 C → 形成 C-N=N-H 中間體
  4. 再從 N=N-H 失質子 → diazo (C-N=N⁻) 中間體
  5. N₂ 氣體離開（很大驅力）→ 留下 carbanion
  6. Carbanion 從水抓 H → 烷類（CH₂R₂）

Clemmensen Reduction（同一個 C=O → CH₂ 轉換，但條件相反）

Wolff-KishnerClemmensen
條件H₂N-NH₂ / KOH / heatZn(Hg) / HCl / heat
環境強鹼強酸
用途不耐酸的基質不耐鹼的基質
20.7 Hydrolysis 水解（Acetal / Imine / Enamine）

三類產物都可以被酸 + 水水解回原本的羰基化合物：

起始物水解條件產物
Acetal R₂C(OR')₂H₂O / H⁺Ketone/aldehyde + 2 R'OH
Imine R₂C=NR'H₂O / H⁺Ketone/aldehyde + R'NH₂
Enamine R₂N-CR=CR₂H₂O / H⁺Ketone/aldehyde + R₂NH
注意：三種水解只有酸催化有效，鹼催化下幾乎不反應（因為 OR、NR 是壞離去基，需要 H⁺ 質子化變好離去基）。
20.8 Sulfur Nucleophiles 硫親核劑 + Raney Ni 還原

Thiol + 羰基 → Thioacetal（硫縮醛）

硫醇（thiol, R-SH）與 ROH 行為類似，酸催化下與羰基反應：

  • R₂C=O + 2 RSH (H⁺) → thioacetal R₂C(SR)₂ + H₂O
  • 用 1,3-propanedithiol → cyclic thioacetal（1,3-dithiane）
  • 用 1,2-ethanedithiol → cyclic thioacetal（1,3-dithiolane）

★ Thioacetal + Raney Ni = 第三種 C=O → CH₂ 的方法

繼 Wolff-Kishner（鹼）與 Clemmensen（酸）之後，第三條路：
R₂C=O + HSCH₂CH₂SH (H⁺) → thioacetal → Raney Ni → R₂CH₂
優點：中性條件！適合酸鹼都不耐的基質。
方法條件適用
Wolff-KishnerH₂NNH₂ / KOH / heat強鹼 — 適合耐鹼的分子
ClemmensenZn(Hg) / HCl / heat強酸 — 適合耐酸的分子
Raney Ni1) HSCH₂CH₂SH / H⁺　2) Raney Ni中性 — 適合不耐酸鹼的分子
20.9 Hydrogen Nucleophiles 氫負離子（H⁻ = hydride）

H 通常是親電的（提供 H⁺），但帶 lone pair 的氫負離子 H⁻（hydride）是強親核劑。

兩個常用 hydride 試劑

試劑強度可還原不可還原
LiAlH₄（LAH）強醛、酮、酯、醯胺、腈、羧酸…幾乎全部—
NaBH₄弱（溫和）醛、酮酯、醯胺、腈、羧酸
機制（兩步）：
  1. Step 1：H⁻ 攻擊 C=O 碳 → alkoxide（O⁻）；溶劑是無水的（乙醚、THF）
  2. Step 2（aqueous workup）：加 H₂O 或 dilute HCl → 質子化 O⁻ → 中性醇
為什麼分兩步？LAH 和 NaBH₄ 都跟酸劇烈反應放出 H₂ 氣體（會爆炸）。所以第一步必須在無酸環境下做，第二步才加水。

反應結果

  • Aldehyde + LAH/NaBH₄ → 1° alcohol
  • Ketone + LAH/NaBH₄ → 2° alcohol
20.10 Carbon Nucleophiles 碳親核劑（Grignard / 氰醇 / Wittig）

碳通常不當親核劑（沒有 lone pair）。要當親核劑必須讓 C 帶 lone pair：

  1. Carbanion（C⁻）：不穩定，難形成（除非有 EWG 穩定，如 enolate、ylide）
  2. 接電負度低的原子（如 Mg、Li）→ Grignard / organolithium

(a) Grignard Reagent（RMgX）

機制：
  1. R–Mg–X 中 R 帶 δ⁻（C–Mg 鍵極化），相當於碳負離子
  2. R⁻ 攻擊 C=O 碳 → alkoxide
  3. Aqueous workup（H₂O 或 H₃O⁺）→ 醇
  • Aldehyde + RMgX → 2° alcohol（除非用 HCHO，得 1° alcohol）
  • Ketone + RMgX → 3° alcohol
  • Ester + 2 RMgX → 3° alcohol（先加 1 個 R，再加第 2 個 R）
  • 含酸性 H 的基質（如 -COOH、-OH、-NH）需要過量 Grignard，因為 Grignard 會先被酸性 H 中和

(b) Cyanohydrin（氰醇）

KCN（或 NaCN）+ HCl + 羰基 → cyanohydrin（α-羥基腈）

合成價值：導入 -CN 後可再轉化成：

  • 1) LAH　2) H₂O → 把 -CN 還原成 -CH₂-NH₂ → 得到 β-amino alcohol
  • H₃O⁺ / heat → 把 -CN 水解成 -COOH → 得到 α-hydroxy acid（α-羥基羧酸）

★ (c) Wittig Reaction（磷葉立德反應）

Wittig 是把 C=O → C=C 的標準方法，產物是已知結構的純烯（沒有 Grignard + 脫水會產生的混合物問題）。

形成 Ylide（葉立德）

  1. Ph₃P (triphenylphosphine) + R–X → Ph₃P⁺–R X⁻（phosphonium salt，SN2）
  2. BuLi（強鹼）拔 α-H → ylide（Ph₃P⁺–CR⁻ ↔ Ph₃P=CR）
Wittig 機制：
  1. Ylide 的 C⁻ 攻擊 C=O 碳 → betaine（兩端帶相反電荷）
  2. O⁻ 攻擊 P⁺ 內分子環化 → oxaphosphetane（4 員環 P-C-C-O）
  3. 4 員環自發 retro-[2+2] → alkene + Ph₃P=O（triphenylphosphine oxide，P=O 鍵很強是驅力）

Wittig vs Grignard + 脫水

WittigGrignard + 脫水
產物單一烯，C=C 在原 C=O 位置常有多個 regioisomer（如 1-methylcyclohexene + methylenecyclohexane 9:1）
限制不適合四取代烯適合大部分情況
20.11 Baeyer-Villiger Oxidation
特殊反應：在 C=O 碳和 α-C 之間插入一個 O 原子，把 ketone 變成 ester。
試劑：過氧酸（RCO₃H，如 mCPBA、CF₃CO₃H）
機制（3 步）：
  1. Peroxyacid 的 OH 端 O 攻擊 C=O → tetrahedral intermediate（帶 -O-O-COR）
  2. 分子內質子轉移（經 5 員環 TS）→ 為下一步準備
  3. Rearrangement（重排）：α-C 上的取代基遷移到 O 上，同時 C=O 重新形成，並推出 carboxylic acid 副產物

★ 遷移順序（哪個取代基會優先遷移）

H > 3° > 2°, Ph > 1° > methyl

  • 對稱酮：兩邊都一樣 → 沒選擇
  • 不對稱酮：根據上述順序選最會遷移的
  • 例：methyl ketone 的非甲基那邊（如 3° 烷基）會遷移 → 得到 ester R-CO-O-CH(R')₂

Ex. 範例題 Practice Problems
範例 1 — 命名 / IUPAC Name
為下列分子寫出 IUPAC 命名：CH₃-CH₂-CH₂-CHO
Provide the IUPAC name for the following: CH₃-CH₂-CH₂-CHO
答案：butanal（丁醛）。母鏈含 4 個 C，醛在 C1，字尾 -al。
範例 2 — 預測產物 / Predict the Product
acetone + ethylene glycol（HOCH₂CH₂OH）+ H⁺（並移除水）會得到什麼？
What is the product when acetone reacts with ethylene glycol in the presence of H⁺ catalyst (with removal of water)?
答案：2,2-dimethyl-1,3-dioxolane（5 員環 cyclic ketal）。acetone 的 C=O 被 2 個 -OR 取代，OR 是同個 ethylene glycol 的兩端 → 形成 5 員環 acetal。
範例 3 — 機制 / Mechanism
畫出 cyclohexanone + methylamine（CH₃NH₂）/ 酸催化 形成 imine 的完整機制（6 步）。
Draw the complete 6-step mechanism for the formation of an imine from cyclohexanone and methylamine under acidic catalysis.
答案步驟（不畫結構，描述文字）：
1. 胺攻擊 C=O 碳 → tetrahedral N⁺ alkoxide
2. 質子轉移（N→O 或經 H₃O⁺）→ carbinolamine（中性 α-胺基醇）
3. OH 被 H⁺ 質子化 → -OH₂⁺
4. H₂O 離開 → iminium ion（C=N⁺(CH₃)(H)）
5. 從 N 失質子 → imine（C=N-CH₃）
6. 反應結束。產物：N-甲基環己亞胺（N-methylcyclohexanimine）
範例 4 — 選擇還原方法 / Choose Reduction Method
基質含一個 ketone 和一個 ester。你想只還原 ketone（變成醇），不動 ester。用什麼試劑？
A substrate contains both a ketone and an ester. You want to reduce only the ketone (to alcohol) without touching the ester. Which reagent?
答案：NaBH₄。NaBH₄ 是溫和還原劑，只還醛/酮，不還 ester / amide。LAH 太強會把 ester 一起還原成醇。
範例 5 — 三種 C=O → CH₂ 方法的選擇 / Choosing Among Three Methods
已知基質含對強鹼敏感的基團（如 ester）。要把分子中的 ketone 還原成 CH₂，不能用哪些方法？
Given a substrate that is sensitive to strong base (e.g., contains an ester), which method(s) cannot be used to reduce a ketone to CH₂?
答案：不能用 Wolff-Kishner（KOH/heat，太鹼，會水解 ester）。可以用：
① Clemmensen（酸性條件，OK）
② Raney Ni（thioacetal → 中性，OK）
範例 6 — Baeyer-Villiger 主產物 / Major Product
2-methylcyclohexanone 與 mCPBA 反應，主產物是哪個 ester？（遷移順序：H > 3° > 2°, Ph > 1° > methyl）
When 2-methylcyclohexanone reacts with mCPBA, which ester is the major product? (Migration order: H > 3° > 2°, Ph > 1° > methyl)
答案：2-methylcyclohexanone 有兩種 α-C：一個是 2° 烷基（CH₂），另一個是 3° 烷基（CH-CH₃，就是含甲基的 α-C）。
根據遷移順序 3° 比 2° 優先，所以是含甲基的 α-C 遷移到 O 上。
產物：7 員環 lactone（ε-caprolactone 變體，氧插在 carbonyl C 與含甲基 α-C 之間）。
★ 期末速查表 Final Cheat Sheet

命名重點

  • 醛 = parent + -al，C=O 永遠 C1
  • 酮 = parent + -one，編號讓 C=O 位置號最小
  • 優先序：酸 > 酯 > 醯氯 > 醯胺 > 腈 > 醛 > 酮 > 醇 > 胺 > 烯 > 炔

反應性

  • 醛 > 酮（立體 + 電性兩個原因）
  • 羰基 C 是親電的三個原因：共振 / 誘導 / sp² 開放

三條重點：C=O → CH₂

  • Wolff-Kishner：H₂NNH₂ / KOH / heat（強鹼）
  • Clemmensen：Zn(Hg) / HCl / heat（強酸）
  • Raney Ni：1) HSCH₂CH₂SH/H⁺ 2) Raney Ni（中性，最溫和）

選擇題

  • 還原醛/酮且不動 ester → NaBH₄
  • 全部還原 → LAH
  • C=O → C=C 單一產物 → Wittig
  • C=O → ester（插 O）→ Baeyer-Villiger (RCO₃H)
  • 保護 C=O 不被親核劑攻擊 → 形成 acetal（H⁺ + 2 ROH 或 ethylene glycol）

機制重點

  • 所有 C=O 親核加成都遵循：先攻擊 C → tetrahedral 中間體 → 質子化（或失質子）
  • 酸催化條件：中間體只能中性 或 +1，避免兩個正/負電荷
  • Imine 形成是 imine：iminium ion 從 N 失質子；enamine：iminium 從 α-C 失質子
  • Wittig 驅力：Ph₃P=O 鍵很強（容易斷 oxaphosphetane）
  • Baeyer-Villiger 遷移順序：H > 3° > 2°, Ph > 1° > methyl
讀完別忘了：跟 Ch 21（羧酸衍生物）相比，醛酮的特點是 C=O 沒有好離去基，所以反應停在「加成」階段；Ch 21 的酸/酯/醯胺有 OR/NR/X 當離去基，反應會繼續到「取代」階段。這是兩章的核心差別。
