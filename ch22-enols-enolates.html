Chapter 22 — Alpha Carbon Chemistry

α 碳化學：烯醇與烯醇鹽 ｜ Enols and Enolates ｜ 期末考重點
本章核心：羰基旁邊的 α 碳上的 H 是酸性的（pKa ~ 17-25），被拔走後形成烯醇鹽（enolate）。
烯醇鹽是極強的親核劑（C 端），可以攻擊各種親電劑（鹵化物、其他羰基、α,β-不飽和羰基）→ 形成 新的 C-C 鍵。
整章基本上就是「如何用烯醇鹽做 C-C 鍵」的各種變體。
22.1 Introduction: Enols & Enolates 烯醇與烯醇鹽

α、β、γ 命名

對於羰基化合物，跟羰基 C 直接相連的碳叫 α，再往外 β、γ、δ。本章專注 α 位的反應。

★ Keto-Enol 互變異構（tautomerization）

Keto form（酮式）⇌ Enol form（烯醇式）
α-H 從 α 碳跑到羰基 O 上，同時 C=O 變 C-O-H、C-C 變 C=C。
這不是共振，是真正的兩個不同分子（不同的 σ 鍵連接），透過 H 的遷移互換。
分子Keto 比例Enol 比例
Acetone99.999999%0.0000001%
Cyclohexanone99.9999%0.0001%
2,4-pentanedione（1,3-diketone）10-30%70-90%（!）
Phenol（特殊：芳香性）< 0.01%> 99.99%
為何 1,3-diketone 的 enol 比例特別高？因為 enol 形成後可以形成分子內氫鍵（六員環，O-H...O=C）+ 共軛烯醇很穩定。Phenol 則因 enol 是芳香性的（苯環），所以完全偏 enol。

★ Enolate 形成機制

酸催化：
  1. C=O 的 O 被質子化 → 共振穩定 carbocation（α 碳變更酸）
  2. 水拔 α-H → 中性 enol
鹼催化：
  1. 鹼直接拔 α-H → 形成共振穩定 enolate（負電在 O 或 α-C）
  2. 質子化（或不質子化，直接當親核劑）

★ Enolate 的雙重身分

Enolate 有兩個共振結構：

  • 負電在 O → 像 alkoxide
  • 負電在 α-C → 像 carbanion
雖然負電主要在 O 上（O 電負度大），但 Enolate 幾乎都用 C 端攻擊親電劑（C-attack 比 O-attack 多）。原因：C-attack 得到 C=O（強鍵），O-attack 得到 C=C + C-O（合計較弱）→ C-attack 熱力學產物較穩。

為何 1,3-dicarbonyl 那麼酸？形成的 enolate 可以共振到兩個 O 上（兩個 C=O 都共振穩定它）→ pKa 降到 9-13，比一般 ROH 還酸！這就是 malonic ester 和 acetoacetic ester 合成的關鍵。

★ 鹼的選擇

鹼pKa(共軛酸)用途

LDA 為何特別好用？① pKa 36 → 可拔 ester（25）甚至 ketone（19），形成定量烯醇鹽 ② 兩個 iPr 太擠 → 只當鹼，不會親核攻擊羰基（避免副反應） ③ 在 -78°C 用 → 形成動力學 enolate（少取代的那邊）。
22.2 α-Halogenation α 鹵化

酸催化 α 鹵化（單取代）

醛/酮 + X₂（Cl₂、Br₂、I₂）/ H₃O⁺ → α-鹵代產物

機制：
  1. 酸催化下，羰基 ⇌ enol（少量但存在）
  2. Enol 的 C=C 是親核劑，攻擊 Br₂ → α-bromo intermediate
  3. 失質子 → α-bromo ketone
酸催化下停在「單取代」，因為加上 Br 後讓 C=O 更難 enolize（Br 是 EWG），第二顆 Br 加不太上去。

不對稱酮的選擇性

反應發生在取代多的 α 碳（more substituted enol 較穩定）。

★ Haloform Reaction 鹵仿反應（鹼催化）

甲基酮（R-CO-CH₃）+ 過量 X₂ / NaOH → 羧酸（R-COO⁻）+ CHX₃
用途：把 methyl ketone 變成羧酸（同時短少一個 C，原本 -COCH₃ 變 -COOH）
同時產生 CHCl₃、CHBr₃、CHI₃（碘仿，黃色固體 → 鑒定 methyl ketone 的試紙反應）
機制（鹼催化下停不下來）：
  1. OH⁻ 拔 α-H → enolate
  2. Enolate 攻擊 X₂ → α-halo ketone
  3. α-Br 是 EWG → 剩下兩個 α-H 更酸 → 又被 OH⁻ 拔 → 再加 X → 持續到 -CX₃
  4. OH⁻ 攻擊 C=O → tetrahedral → -CX₃ 變成好離去基（穩定 carbanion，因 3 個 EWG）→ 離開
  5. 得羧酸 + ⁻CX₃ → CHX₃

★ Hell-Volhard-Zelinskii (HVZ) 反應

羧酸 + Br₂ / PBr₃ → α-bromo carboxylic acid
原因：acid / ester / amide 不會 enolize（α-H 不夠酸 + 反應太慢），所以普通 Br₂ 無效。需要 PBr₃ 先把 -COOH 變 acid bromide → 才能 enolize → Br₂ 加成 → 水解回 α-Br-COOH。
22.3 ★ Aldol Reactions 醛醇反應

基本 Aldol

2 × 醛/酮 + NaOH（催化量）→ β-hydroxy 醛/酮
aldol = aldehyde + alcohol（OH 在 β 位）
機制：
  1. OH⁻ 拔 α-H → enolate
  2. Enolate 的 α-C 攻擊另一個羰基分子的 C=O → 形成新 C-C 鍵 + alkoxide
  3. Alkoxide 從水拿 H → 中性 β-hydroxy 醛/酮（aldol）

平衡考量

基質Aldol 產率原因
Acetaldehyde（無 α-取代）高立體不擁擠，平衡偏產物
Phenylacetaldehyde（PhCH₂CHO）90%產物有額外共軛穩定
2-Methylpropanal（(CH₃)₂CHCHO）低立體擁擠，平衡偏反應物
Cyclohexanone（酮）22%酮比醛差，平衡偏反應物

★ Aldol Condensation（醛醇縮合）

Aldol 產物加熱（或在強鹼下）→ 失水 → 形成 α,β-unsaturated 羰基（共軛烯酮）
2 醛/酮 → α,β-unsaturated 羰基 + H₂O（總反應）
失水機制（兩種）：
鹼催化（E1cb）：① 拔 α-H 形成 enolate ② -OH 離去 → 形成 C=C
酸催化（E1）：① -OH 被質子化變 -OH₂⁺ ② -OH₂ 離去成 carbocation ③ 失 α-H 形成 C=C
為什麼縮合產物常常較穩？① C=C 跟 C=O 共軛，有額外穩定 ② 失水放出小分子，熵增 ③ 通常會繼續延伸共軛（如苯環旁的 aldol）→ 平衡大幅偏向縮合產物。

Mixed Aldol（交叉醛醇）— 一般沒用

2 個不同的醛/酮 + 鹼 → 4 個產物（兩兩配對）→ 沒用

★ 兩個解決方法

方法策略
① 一邊無 α-H用 HCHO（甲醛）或 PhCHO（苯甲醛）當「acceptor」（沒 α-H 不能當 donor）；另一邊有 α-H 當 donor → 只有一個結果
② 用 LDA 先做完整 enolate① 第一個基質 + LDA → 形成定量 enolate ② 慢慢加第二個基質 → 純單一產物

Intramolecular Aldol（分子內醛醇）

1,4- 或 1,5-diketone + 鹼 → 形成環狀 α,β-unsaturated ketone（最小環張力的環會贏，通常是 5、6 員環）。

起始物產物
2,5-Hexanedione（1,4-diketone）3-Methyl-2-cyclopentenone（5 員環）
2,6-Heptanedione（1,5-diketone）3-Methyl-2-cyclohexenone（6 員環）
22.4 Claisen Condensation 克萊森縮合
2 × ester + 1 當量 NaOEt → β-keto ester
「Aldol」用於醛/酮（停在加成）；「Claisen」用於 ester（走取代，因 ester 有 -OR 離去基）。
機制：
  1. NaOEt 拔 ester 的 α-H → ester enolate（少量，因 ester pKa 25 vs EtOH pKa 16，平衡不利）
  2. Ester enolate 攻擊另一個 ester 的 C=O → 四面體中間體
  3. -OEt 離去（不像 aldol 沒離去基！）→ β-keto ester 中間體
  4. β-keto ester 的 α-H 非常酸（pKa 11）→ 被 NaOEt 完全去質子化 → doubly stabilized enolate
  5. 這一步把整體平衡推向產物（即使前面平衡不利）
  6. 實驗最後加 H₃O⁺ → 中性 β-keto ester
為何要等量 NaOEt 而非催化量？因為要在最後一步「完全去質子化」β-keto ester（推平衡），需要至少 1 當量 NaOEt。

★ Dieckmann Cyclization（分子內 Claisen）

Diester + NaOEt → 環狀 β-keto ester
Diester 自身分子內 Claisen → 形成 5 或 6 員 β-keto ester
起始物產物
Diethyl hexanedioate（1,6-diester，4 個 CH₂ 隔開）Ethyl 2-oxocyclopentanecarboxylate（5 員環）
Diethyl heptanedioate（1,7-diester）Ethyl 2-oxocyclohexanecarboxylate（6 員環）
22.5 ★ Alpha Alkylation α 烷化

基本烷化

  1. 羰基 + LDA → 完全 enolate
  2. Enolate（C 端）攻擊烷基鹵化物 → SN2 取代
  3. 得 α-烷化羰基
限制：烷基鹵化物只能是 methyl 或 1°（SN2）。2°、3° → enolate 變鹼 → 走 E2 消除而非取代。

Kinetic vs Thermodynamic Enolate（動力學 vs 熱力學）

不對稱酮（α 碳兩邊不一樣）→ 兩種 enolate 可能：

Kinetic（動力學）Thermodynamic（熱力學）
形成位置少取代的 α-C（H 較易被拔）多取代的 α-C
產物穩定性較低（C=C 取代少）較高（C=C 取代多 = 更穩）
條件LDA, -78°C（強鹼、低溫、不可逆）NaH, 25°C（鹼較弱、室溫、可逆 → 達熱力學平衡）

★ Malonic Ester Synthesis（丙二酸酯合成）

把烷基鹵化物 R-X 變成羧酸 R-CH₂-COOH（增加 2 個 C）
步驟：
  1. Diethyl malonate（EtO₂C-CH₂-CO₂Et）+ NaOEt → doubly stabilized enolate（pKa 13，很酸）
  2. + R-X → SN2 → R-取代 malonate
  3. + H₃O⁺ / heat → 水解兩個 ester → diacid（malonic acid 衍生物）
  4. Diacid 加熱 → decarboxylation（脫羧）（因 β-keto acid 機制，CO₂ 跑掉）→ 單羧酸 R-CH₂-COOH
Decarboxylation 條件：羧酸 β 位有羰基（β-keto acid 或 malonic acid 衍生物）→ 加熱即可失 CO₂（六員環過渡態，類似 keto-enol）。

Acetoacetic Ester Synthesis（乙醯乙酸酯合成）

類似 malonic ester，但起始物是 ethyl acetoacetate（CH₃CO-CH₂-CO₂Et）。產物是甲基酮 R-CH₂-COCH₃（不是羧酸）。

  1. Ethyl acetoacetate + NaOEt → enolate
  2. + R-X → SN2
  3. H₃O⁺ / heat → 水解 ester + 脫羧 → 得 R-CH₂-CO-CH₃（α-取代甲基酮）

雙烷化

Malonic ester / acetoacetic ester 可連續烷化兩次（取代兩個 H）→ 得 R₁R₂CH-COOH 或 R₁R₂CH-COCH₃。

22.6 ★ Conjugate Addition: Michael Reaction 共軛加成

α,β-Unsaturated 羰基的三個共振結構

C=C-C=O 有共振 → β-碳也帶 δ⁺（除了羰基 C 之外的另一個親電位）。

★ 1,2- vs 1,4- 加成

親核劑類型攻擊位置類型
強親核劑（Grignard, LAH）羰基 C（位置 2）1,2-addition（直接加 C=O）
軟親核劑（Gilman R₂CuLi, 穩定 enolate, RSH, NH₃）β-C（位置 4）1,4-addition / Conjugate addition / Michael
記憶口訣：「強硬攻擊 C=O；軟弱繞過去打 β」。Grignard 太強 → 一抓就攻擊最近的（C=O）；Gilman 較軟 → 給時間挑遠的（β）。

★ Michael Reaction

穩定 enolate（Michael donor）+ α,β-unsaturated 羰基（Michael acceptor）→ 1,5-dicarbonyl
Michael donors（捐贈者，提供 enolate）Michael acceptors（接受者）
1,3-diketone（pKa 9）α,β-unsaturated 醛
β-keto ester（pKa 11）α,β-unsaturated 酮
Malonic ester（pKa 13）α,β-unsaturated ester
β-keto nitrileα,β-unsaturated amide
α-Nitro 化合物α,β-unsaturated nitrile
R₂CuLi（Gilman）α,β-unsaturated nitro

Stork Enamine Synthesis

另一種做 Michael 的方法，用 enamine（醛酮 + 2° 胺）當親核劑：

  1. Ketone + 2° amine（如 pyrrolidine）/ H⁺ → enamine
  2. Enamine + Michael acceptor → 共軛加成（enamine 的 α-C 攻擊 β-C）
  3. 水解 enamine（H₃O⁺）→ 回到 ketone + 胺

淨結果：α-C 上連上了 Michael acceptor 那邊 → 1,5-dicarbonyl 產物。

22.7 Synthetic Strategies + Robinson Annulation 合成策略

★ 用反應產物的「官能基距離」反推用什麼反應

反應產物官能基結構
Aldol1,3-difunctional（β-hydroxy carbonyl 或 α,β-unsaturated carbonyl）
Claisen1,3-dicarbonyl（β-keto ester）
Michael / Stork1,5-dicarbonyl
合成題的解法心法：看產物中兩個官能基的距離 → 直接套上面的對應 → 反推用什麼反應。

★ Robinson Annulation

Michael + 分子內 Aldol = 建構六員環的標準方法
2-cyclohexenone 衍生物 = Robinson 產物
步驟：
  1. 第一步 Michael：Michael donor + α,β-unsaturated ketone → 1,5-dicarbonyl 中間體
  2. 第二步 分子內 aldol condensation：1,5-dicarbonyl 自身環化 → 6 員環 α,β-unsaturated ketone

常用：3-buten-2-one（MVK, methyl vinyl ketone）是最常用的 Michael acceptor。

Ex. 範例題 Practice Problems
範例 1 — pKa 比較 / Acidity
下列哪個分子的 α-H 最酸？(A) acetone（CH₃COCH₃）　(B) acetic acid（CH₃COOH）　(C) 2,4-pentanedione（CH₃COCH₂COCH₃）　(D) ethyl acetate（CH₃COOC₂H₅）
Which compound has the most acidic α-H? (A) acetone　(B) acetic acid　(C) 2,4-pentanedione　(D) ethyl acetate
答案：(C) 2,4-pentanedione（pKa = 9）
‧ (A) acetone：pKa 19（α-H 一邊有 C=O）
‧ (B) acetic acid：pKa 5 但這是 O-H 不是 α-H（題目問 α-H）
‧ (C) 2,4-pentanedione：pKa 9（α-H 兩邊都有 C=O，雙重共振穩定）
‧ (D) ester：pKa 25（最不酸）
注意題目問 α-H，所以 (B) 的 -OH 不算。
範例 2 — 鹵仿反應 / Haloform
2,2-dimethyl-3-pentanone（(CH₃)₃C-CO-CH₂CH₃）+ 過量 Br₂ / NaOH，再 H₃O⁺，主產物為何？
What is the major product when 2,2-dimethyl-3-pentanone reacts with excess Br₂/NaOH, then H₃O⁺?
答案：實際上沒有 haloform 反應。Haloform 需要 methyl ketone（CH₃-CO-R）。
這個分子是 R-CO-CH₂CH₃（ethyl 不是 methyl），所以只會做單一 α-bromination 在 CH₂ 那邊（OH⁻ 拔最容易的 α-H）→ R-CO-CHBr-CH₃。
如果題目改成 R-CO-CH₃（如 pinacolone, (CH₃)₃C-CO-CH₃）才能 haloform → R-COO⁻ + CHBr₃。
範例 3 — Aldol 產物 / Aldol Product
propanal（CH₃CH₂CHO）+ NaOH / H₂O → 主產物為何？再加熱會變什麼？
What is the main product when propanal reacts with NaOH/H₂O? What happens upon heating?
Step 1（aldol addition）：
OH⁻ 拔 α-H（CH₃-CH₂-CHO 的 CH₂）→ enolate → 攻擊另一個 propanal 的 C=O
產物：3-hydroxy-2-methylpentanal（CH₃CH₂CH(OH)CH(CH₃)CHO）

Step 2（heating → condensation）：失水
產物：2-methyl-2-pentenal（CH₃CH₂CH=C(CH₃)CHO）（α,β-unsaturated 醛）
範例 4 — 合成設計 / Synthesis Design
用 ethyl acetoacetate（CH₃COCH₂COOEt）合成 5-methyl-2-hexanone（CH₃COCH₂CH₂CH(CH₃)₂）。
Synthesize 5-methyl-2-hexanone from ethyl acetoacetate.
步驟：
1) NaOEt 拔 ethyl acetoacetate 的 doubly-α-H → enolate
2) + isobutyl bromide（(CH₃)₂CHCH₂Br，SN2）→ α-取代 ester
3) H₃O⁺ / heat → 水解 ester + 脫羧 → 5-methyl-2-hexanone = CH₃-CO-CH₂-CH₂-CH(CH₃)₂

這是 acetoacetic ester synthesis 標準用法（增加 alkyl 在 -COCH₂- 位置）。
範例 5 — Michael 機制 / Mechanism
解釋為何 Gilman reagent（R₂CuLi）對 α,β-unsaturated ketone 做 1,4-加成，而 Grignard（RMgBr）做 1,2-加成？
Why does Gilman reagent (R₂CuLi) give 1,4-addition with α,β-unsaturated ketones, while Grignard (RMgBr) gives 1,2-addition?
答案：
‧ Grignard 太「硬」、太活性：直接抓最近的親電位 = C=O 的 C（動力學產物，直接加成）
‧ Gilman 較「軟」、較不活性：給反應時間平衡到熱力學產物 = β-C（更遠但共軛穩定 enolate 中間體）

硬軟酸鹼（HSAB）：硬親核（O 或負電集中）配硬親電（C=O 的 C）；軟親核（C 上負電擴散）配軟親電（共軛 β-C）。
範例 6 — 反推用什麼反應 / Identify Reaction Type
給三個產物，分別用哪個反應合成？
(A) 1,3-diketone（CH₃COCH₂COCH₃）
(B) β-hydroxy aldehyde（CH₃CH(OH)CH₂CHO）
(C) 1,5-diketone（CH₃COCH₂CH₂CH₂COCH₃）
Identify the reaction type for each: (A) 1,3-diketone　(B) β-hydroxy aldehyde　(C) 1,5-diketone
答案：
(A) 1,3-diketone → Claisen 變體（或 Claisen 衍生反應，C₁ 跟 C₃ 都是 C=O）
(B) β-hydroxy aldehyde → Aldol addition（標準 aldol 產物）
(C) 1,5-diketone → Michael / Stork enamine synthesis
★ 期末速查表 Final Cheat Sheet

α-H 酸性順序（必背）

  • 1,3-diketone（9） < β-keto ester（11） < malonic ester（13） < 醛（17） < 酮（19） < ester（25） < amide（30）

4 大反應對應 4 種產物

  • α-Halogenation：醛/酮 + X₂/H⁺ → α-halo（單取代）；甲基酮 + X₂/OH⁻ → 羧酸 + CHX₃（haloform）
  • Aldol：2×醛/酮 + 鹼 → β-hydroxy 羰基（加熱失水 → α,β-unsaturated 羰基）
  • Claisen：2×ester + NaOEt → β-keto ester（1,3-dicarbonyl）
  • Michael / Stork：donor + α,β-unsat → 1,5-dicarbonyl

從產物反推

  • 產物有 β-OH 或 α,β-C=C：Aldol
  • 產物 1,3-dicarbonyl：Claisen（如果有 ester）或其他
  • 產物 1,5-dicarbonyl：Michael / Stork
  • 含 6 員環 α,β-unsaturated ketone：Robinson annulation

選試劑

  • 要完全去質子化 ester → LDA, -78°C（強鹼、大塊頭、不會親核攻擊）
  • 要熱力學 enolate → NaH, 25°C（可逆，達平衡）
  • 動力學 enolate → LDA, -78°C（不可逆，取少取代那邊）
  • 軟親核（要 1,4-加成）→ Gilman R₂CuLi、1,3-dicarbonyl enolate
  • 硬親核（1,2-加成）→ Grignard、LAH

增加碳的方法（C-C 鍵形成）

  • Malonic ester synthesis：R-X → R-CH₂-COOH（增 2 C）
  • Acetoacetic ester synthesis：R-X → R-CH₂-CO-CH₃（增 2 C 變甲基酮）
  • Aldol：2 × C → 1 個 4-6 C 連續分子
  • Michael：donor + acceptor → 1,5-dicarbonyl
  • Robinson：建構 6 員環
跟 Ch 20, 21 對照記憶：
Ch 20（醛酮）：親核劑攻擊 C=O 的 C（羰基 C），停在加成 → 醇等
Ch 21（羧酸衍生物）：親核劑攻擊 C=O 的 C，因有離去基所以走取代 → 衍生物互轉
Ch 22（α 碳）：羰基本身當「酸」，α-C 變親核劑去攻擊別的東西 → 形成新 C-C 鍵
三章從不同角度看羰基，全部串起來就是有機合成最重要的方法集合。
