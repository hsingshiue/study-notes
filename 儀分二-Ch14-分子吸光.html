儀器分析（二）— Ch 14

Molecular UV-Vis Absorption · Absorbing Species · Chromophore & Auxochrome
來源：手寫筆記 4 頁 + 板書 2 張 + 課本 Fig 14-3、Table 14-1、Table 14-4

本章回答一個問題：分子「為什麼」會吸收 UV-Vis 光？答案是電子從佔據的分子軌域被激發到反鍵結軌域。接著看有機分子（chromophore）、無機離子與錯合物（d–d、電荷轉移）各自靠哪種躍遷吸光，最後看取代基與溶劑如何把吸收峰推移。

14A 分子軌域 · Molecular Orbitals

兩個原子軌域（如兩個 s 軌域）結合，會產生兩個分子軌域，一個能量降低、一個能量升高：

Bonding orbital 鍵結軌域（σ、π）

能量比原本的原子軌域低，電子密度集中在兩核之間。基態電子優先填入。

Antibonding orbital 反鍵結軌域（σ*、π*）

能量比原子軌域高，兩核之間有節面。基態時空著，電子吸光後跳上來。

左：兩個 s 軌域結合成 σ（能量降）與 σ*（能量升）。右：有機分子軌域能階 σ < π < n < π* < σ*
n 軌域 nonbonding orbital — 通常是 O、N、S 上的孤對電子，不參與鍵結，能量介於 π 與 π* 之間。
A = ε · b · c
ε（莫耳吸光係數）反映的是該躍遷發生的機率（筆記註記：ε ↔ PA）。機率高 → ε 大 → 吸光強。
14B 有機分子的典型電子躍遷 · Typical Electron Transitions核心
Typical electron transitions in organic molecules（依手寫筆記 p.1 重繪）
Why not transition beginning at σ?
對大部分單鍵而言，激發能量太高（excitation energy is sufficiently high）→ 吸收落在遠紫外 / 真空 UV 區。但大氣本身也強烈吸收這段 UV（atmosphere also absorbs UV radiation strongly），一般 UV-Vis 儀器量不到，所以 σ → σ* 不在討論範圍。

三種躍遷的特性比較

躍遷能隙 / 波長機率 & ε需要的結構
① n → σ* 高能隙，吸收波長落在 UV 區 較不容易發生（less probably occur）
ε ≈ 100 ~ 3000 L·mol⁻¹·cm⁻¹（moderate）		 飽和分子上有孤對電子的雜原子（醇、胺、醚、硫醚、鹵化物）
② n → π* 能隙把吸收帶推進 UV-Vis 區（250 ~ 700 nm） 低機率（P small, ε low）
ε ≈ 10 ~ 100		 雜原子孤對電子 + 相鄰 π 鍵（C=O、N=N、N=O）
③ π → π* UV-Vis 區 高機率（high ε）
ε ≈ 10³ ~ 10⁵		 必須有不飽和官能基提供 π 軌域 → 這個官能基就是 chromophore
記法：三種躍遷都是「把電子送進 π* 或 σ*」。從 n 出發 → 波長長但 ε 小（n→π*）或波長短（n→σ*）；從 π 出發到 π* → 最強、最常用來做定量的吸收。

14D 無機物種的吸光 · Absorption of Inorganic Species板書

陰離子 Anions

1
陰離子的吸光是非鍵結電子被激發的結果（a result of excited nonbonding electrons）→ 走 n → σ* 與 n → π*。
2
Nitrate（NO₃⁻）✗ — 板書特別標記硝酸根「不算」典型可用的吸收（其 n→π* 落在 313 nm 附近且 ε 極低，分析上不好用）。

陽離子 Cations ①：前兩列過渡金屬離子 — d–d 躍遷

第一、第二過渡系列（the first two transition series）的離子，因為 d 軌域部分填滿（與氧化態有關），會在可見光區吸收寬帶（absorb broad bands of visible radiation）→ 這就是過渡金屬水溶液有顏色的原因。

陽離子 ②：錯合物 Complexes

錯合物的吸收牽涉已填滿與未填滿 d 軌域之間的躍遷（transition between filled and unfilled d-orbital），而這些 d 軌域的能量取決於配位基（energies that depend on the ligands）→ 換配位基，顏色就變。

板書例子 [Fe(CN)₆]³⁻；右側示意配位基場分裂：Δ 大小由配位基決定，吸收波長跟著變
板書列出的錯合物例子：[Fe(CN)₆]³⁻（Fe³⁺，六個 CN⁻）、[Ni(H₂O)₄]²⁺（板書寫 4 個水，課本水合離子常寫成 6 配位）、[Fe(SCN)ₙ]³⁻ⁿ（電荷轉移的例子，見下）。

陽離子 ③：電荷轉移吸收 Charge-Transfer Absorption

錯合物還有另一種吸光方式：電子從「電子給體」轉移到「電子受體」（electron donor → electron acceptor）。給體通常是配位基、受體通常是金屬離子（或反過來）。

例：[Fe(SCN)ₙ]³⁻ⁿ（血紅色）— SCN⁻ 的電子被激發到 Fe³⁺ 的空軌域 → 瞬間形成 Fe²⁺ 與 SCN 自由基的激發態。
例：Cr₂O₇²⁻（Fig 14-3 第二張）— Cr(VI) 沒有 d 電子，卻在 < 400 nm 有 ε ≈ 8000 的強吸收 → 就是 O → Cr 的電荷轉移。

d–d 躍遷

  • 電子在同一個金屬的 d 軌域之間跳
  • 對稱性禁制 → ε 小（1 ~ 100）
  • 吸收寬帶、位置隨配位基變

電荷轉移吸收

  • 電子在配位基 ⇄ 金屬之間跳
  • 允許躍遷 → ε 大（> 10,000）→ 靈敏度高，常用於定量
  • 需要一方會給電子、一方會收電子
14E 影響吸收的因素 · 取代基與溶劑板書

Chromophore 的 λmax 與 εmax 只是粗略指引，實際位置會被兩件事改變：

1
取代基 Substitution — 以芳香族碳氫化合物（aromatic hydrocarbons）為例，看 Table 14-4。
2
溶劑 Solvent — 極性溶劑會使 n→π* 藍移、π→π* 紅移（筆記只點到，細節課本 14A-2）。

14F Auxochrome 助色團板書定義必背
Auxochrome 助色團：a functional group that does not itself absorb in the UV region, but has the effect of shifting chromophore peaks to longer wavelength, increasing the intensity (ε).
一個本身不在 UV 區吸光的官能基，但接上去後會把 chromophore 的吸收峰推向長波長，並增加吸收強度（ε）。

取代基 ①：中性 Neutral — –OH、–NH₂

板書以 phenol（苯酚） 為例：O 上的一對 n 電子會與環的 π 電子交互作用（pair of n electrons interact with the π electrons of ring）→ 這個交互作用穩定了 π* 態（stabilizing the π* state）→ π 與 π* 的能隙 ΔE 變小 → 吸收波長變長 → red shift。

板書圖重繪：–OH 的 n 電子與環 π 作用 → π* 被穩定（下移）→ 能隙縮小
驗證（Table 14-4）：
苯 B 帶 256 nm（ε 200）→ 苯酚 270 nm（ε 1450）→ 苯酚鹽 287 nm（ε 2600）。
苯 → 苯胺 280 nm（ε 1430）；但苯胺鹽（–NH₃⁺）退回 254 nm（ε 160）。
→ –OH、–NH₂ 正是教科書級的 auxochrome：本身不吸 UV，卻讓 λ 變長、ε 變大；孤對一被質子占用，效果就消失。
Chromophore vs Auxochrome 一句話：chromophore 是「自己會吸光的不飽和基」；auxochrome 是「自己不吸光、但有孤對電子可以塞進 π 系統，讓旁邊的 chromophore 紅移＋變強」的飽和基（–OH、–NH₂、–OR、–SH、鹵素）。

⚡ 30 秒速記
能階順序：σ < π < n < π* < σ*。三種躍遷：n→σ*（UV、ε 100~3000）、n→π*（250~700 nm、ε 小）、π→π*（ε 大、需 chromophore）。σ→σ* 不談：能量太高 + 大氣吸收。
無機：陰離子靠 n 電子（nitrate ✗）；過渡金屬離子 d–d 寬帶、ε 小；錯合物 d 軌域能階由配位基決定；電荷轉移 donor→acceptor、ε 大（[Fe(SCN)ₙ]³⁻ⁿ、Cr₂O₇²⁻）。
苯三帶：E₁ 184（不談）、E₂ 204 nm ε 7900、B 256 nm ε 200。取代基 → E₂、B 帶紅移。
Auxochrome：自己不吸 UV，把 chromophore 峰推向長波長 + ε 變大。機制：–OH / –NH₂ 的 n 電子與環 π 作用 → 穩定 π* → ΔE 縮小。證據：phenol 270 → phenolate 287；aniline 280 → anilinium 254。
