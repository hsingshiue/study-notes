§1 名詞解釋
107 Q1 名詞解釋（14 pts）107

(a) Haloform reaction（鹵仿反應）

Haloform reaction.

答：甲基酮（CH₃-CO-R）在過量鹵素 + 強鹼 NaOH 下，α-碳三個 H 全被取代成 CX₃，CX₃⁻ 為好離去基 → 生成 R-COO⁻ + CHX₃（haloform）。考點：產物是 羧酸而非鹵化酮；判斷依據是 甲基酮 / 仲醇。

(b) HVZ reaction（Hell-Volhard-Zelinsky 反應）

HVZ reaction.

答：羧酸 + PBr₃（或 P + Br₂）→ 經 acyl bromide 中間體 → α-碳被溴化 → 加水水解得 α-bromo carboxylic acid。這是讓羧酸進行 α 取代的標準方法。

(c) Keto-enol tautomer（酮-烯醇互變異構物）

Keto-enol tautomer.

答：α-H 在 keto 形式（C=O）與 enol 形式（C=C-OH）之間互換，差別只在一個 H 的位置與雙鍵位置。常溫下 keto 為主（>99%），但 enol 是 α-取代的關鍵中間體（HVZ、halogenation、Aldol 全靠它）。

(d) Nitrile hydrolysis（腈水解）

Nitrile hydrolysis.

答：R-C≡N + H₃O⁺ / H₂O / heat → R-CONH₂ → R-COOH（兩步水解，先變 amide 再變 acid）。是將 -CN 拉長一碳並轉成羧酸的常用法。

(e) Acid halide（醯鹵）

Acid halide.

答：R-CO-X（X = Cl 居多），羧酸衍生物中反應性 最高者。製法：R-COOH + SOCl₂ 或 PCl₃。在反應性順序中：醯鹵 > 酸酐 > 酯 > 醯胺。

(f) Fischer Esterification（費雪酯化）

Fischer Esterification.

答：R-COOH + R'-OH（酸催化，常用 H₂SO₄）⇌ R-COOR' + H₂O，是 平衡反應。透過 Le Chatelier 原理移除水或加過量醇推動正向。機制：PADPED（質子化 → 加成 → 質子轉移 → 脫水 → 去質子）。

(g) Lactone / Lactam（內酯 / 內醯胺）

Lactone and lactam.

答：分子內成環 → lactone 是 環狀酯，lactam 是 環狀醯胺。常見 γ-丁內酯（5-員 lactone）、ε-己內醯胺（caprolactam，做 Nylon-6 的原料）。
111 Q1 名詞解釋（10 pts）111

(a) Aldol reaction（醛醇縮合）

Aldol reaction.

答：兩分子醛 / 酮在鹼催化下，一者去 α-H 形成 enolate，作為親核劑攻擊另一者的 C=O，生成 β-hydroxy carbonyl。加熱條件可進一步脫水成 α,β-不飽和羰基化合物（Aldol condensation）。

(b) Michael Addition reaction（麥可加成）

Michael Addition reaction.

答：穩定 enolate（如 malonate、β-酮酯）作為親核劑（Michael donor），對 α,β-不飽和羰基化合物（Michael acceptor）進行 1,4-共軛加成，得 1,5-二羰基產物。Robinson annulation 的第一步即為此。

(c) Baeyer-Villiger oxidation（B-V 氧化）

Baeyer-Villiger oxidation.

答：酮 + 過氧酸（mCPBA 等）→ 在 C-CO 之間插入一個 O → 變成酯。遷移基團優先序：3° > 2° > phenyl > 1° > methyl。考點：環酮會擴環變 lactone。

(d) Dieckmann Cyclization（迪克曼環化）

Dieckmann Cyclization.

答：分子內的 Claisen 縮合。雙酯（如 diethyl adipate）在 NaOEt 下，一端 α-碳變 enolate 攻擊另一端酯羰基 → 環狀 β-酮酯（5 或 6 員環最佳）。

(e) Lactone and lactam（內酯 / 內醯胺）

Lactone and lactam.

答：同 107 (g)。Lactone = 環狀酯；lactam = 環狀醯胺。例如 6-aminohexanoic acid + DCC → ε-caprolactam（111 Q10 機制題）。
名詞解釋拿分技巧：每題寫「定義 + 試劑/條件 + 一個範例或關鍵點」，大約 2-3 行即可。不要只抄定義，加一句「機制要點」或「產物特性」會多拿 1-2 分。
§2 IUPAC 命名
107 Q5 IUPAC 命名（15 pts，5 個化合物）107

寫出下列化合物的 IUPAC 名稱（請注意 第一個字母必須大寫，且立體化學記號 R/S 大寫）。

Give IUPAC names for the following 5 compounds. (15 pts)

共通要點：
  • 羧酸：母體鏈含 -COOH，編號從 -COOH 開始（C1）。-CH₃ 取代為 methyl-，-OH 為 hydroxy-。
  • 酯：「O-基團 + 母體酸 -oate」，例如 Ethyl butanoate（CH₃CH₂CH₂-CO-O-CH₂CH₃）。
  • 醯胺：母體酸去 -oic acid → -amide。N 上取代基寫 N-。
  • 酸酐：兩個酸名 + anhydride，相同則寫一次（acetic anhydride）。
  • 腈：母體鏈含 C≡N，-nitrile，碳氮算 C1。
111 Q2 IUPAC 命名（9 pts，3 個化合物）111

(a) 結構：CH₃CH₂CH₂-CO-O-CH₂CH₃（丁酸乙酯）

Give IUPAC name for ester (CH₃CH₂CH₂COOCH₂CH₃).

答：Ethyl butanoate（學生答 "Ethyl butyrate" 是慣用名，IUPAC 應使用 butanoate）。

(b) 苯環 + COOH（C1）+ CN（C3）

Benzoic acid with CN at meta position.

答：3-Cyanobenzoic acid（學生答 "3-Cyano-1-benzoic acid"，「1-」可省略，benzoic acid 默認 COOH 在 C1）。

(c) 苯甲酸（Ph-CO-）與丁酸（CH₃CH₂CH₂-CO-）的混合酸酐

Mixed anhydride of benzoic acid and butanoic acid.

答：Benzoic butanoic anhydride（混合酸酐命名：兩個酸名依字母順序，去 acid 加 anhydride）。
命名小提醒：IUPAC 規則新版（1993 起）允許 acid 命名時省略 locant 「1-」，但若有其他取代基且需要區分 ortho/meta/para 時，用 1, 3, 4 等數字明確標示。寫答案時一律 第一個字母大寫（句首大寫規則）。

起始物 → 目標標準試劑關鍵點

§6 連續反應 A→B→C（雙生物鹼題）
107 Q8 / 111 Q8 連續反應預測（同題型出兩年）兩年

起始物為含 -OCH₃（甲酯）與 -O-CO-Ph（苯甲酸酯）的雙取代 tropane / 莨菪烷類生物鹼（含 N），條件為：

  • i = acid hydrolysis（酸水解）→ 產物 A
  • ii = oxidation（氧化）→ 產物 B
  • iii = heat（加熱）→ 產物 C

同時生成 CH₃OH + C₆H₅CO₂H。

Please tell each reaction condition and predict the structure of A~C (hint: i = acid hydrolysis, ii = oxidation, iii = heat).

分析：
  1. i：酸水解兩個酯鍵 → 釋出 CH₃OH 與 PhCOOH，留下兩個 -OH（A 為 diol 形式）。
  2. ii：兩個 -OH 氧化成 C=O → B 為 diketone（或 keto-alcohol）。
  3. iii：加熱使 β-hydroxy ketone 或 β-diketone 分子內脫水 / 重排，C 為環狀烯酮或縮醛。
§7 機制題（占分最重）

7-1. 環縮小 / Favorskii 重排

107 Q9 Favorskii 環縮小（8 pts）107

下列反應為 分子內 Favorskii 反應，由鹼處理 α-溴酮後產生 環縮小產物。寫出兩步驟與其機制。

The following reaction involves an intramolecular Favorskii reaction followed by α-bromo ketone with base to yield a ring-contracted product. Write both steps, and their mechanisms.

機制要點：
  1. NaOH 拔走 α-H（非離去基側）→ enolate
  2. enolate 之 α-C 從背面攻擊 α-C-Br → 形成 三員環中間體（cyclopropanone） → Br⁻ 離去
  3. OH⁻ 攻擊三員環酮羰基 → 開環，C-C 鍵斷在較取代側
  4. 質子化 → 得到比原本 少一員環的羧酸
考點：cyclopropanone 是關鍵中間體，畫不出來就拿不到分。

7-2. Beckmann 重排（→ caprolactam）

111 Q9 Beckmann 重排（6 pts）111

環己酮先轉成 oxime（用 NH₂OH），用酸處理 oxime 進行 Beckmann 重排得到 caprolactam。寫出所有步驟與機制。

The following reaction involves a Beckmann reaction followed by cyclohexanone which is first converted to its oxime. Treatment of this oxime with acid induces the Beckmann rearrangement to give caprolactam. Write all steps, and their mechanisms.

機制：
  1. cyclohexanone + NH₂OH → oxime（C=N-OH）
  2. 酸質子化 -OH → -OH₂⁺（變好離去基）
  3. 反位（anti）的 C-C 鍵帶電子對 遷移到 N，同時 H₂O 離去 → 生成 nitrilium ion（C=N⁺-R）
  4. H₂O 攻擊 C → 加水質子轉移 → 最後互變異構（tautomer）為 amide
  5. 得到 ε-caprolactam（7-員環醯胺，Nylon-6 原料）

7-3. Dieckmann + 脫羧 / Claisen 縮合

111 Q5 機制：Claisen / Dieckmann + decarboxylation（10 pts）111

寫出下列轉換的機制（涉及 NaOCH₃/EtOH 與 H₃O⁺/heat）：

Propose a mechanism to account for the following transformation. (1. NaOCH₃ / EtOH, 2. H₃O⁺ / heat)

機制：
  1. NaOCH₃ 拔 α-H → enolate
  2. 分子內 enolate 攻擊另一端 ester C=O → tetrahedral 中間體
  3. OEt⁻ 離去 → β-keto ester（Dieckmann 產物）
  4. H₃O⁺/heat 水解酯成酸 → β-keto acid
  5. 加熱 decarboxylation（環狀過渡態，失 CO₂）→ 最終酮
111 Q6 機制：malonate → γ-butyrolactone 系列（6 pts）111

寫出機制（diethyl malonate + NaOEt + 環氧乙烷, 3. H₃O⁺/heat, 4. H₃O⁺）。

Propose a mechanism to account for the following transformation.

機制：malonate enolate 開環攻擊 epoxide → 得 γ-hydroxy diester → 水解雙酯 → 脫羧 → 分子內酯化形成 γ-butyrolactone（5-員 lactone）。

7-4. Robinson Annulation（環化縮合）

111 Q11 & Q14 Robinson Annulation 機制（共 14 pts）111

寫出下列 Robinson Annulation 反應機制（KOH / EtOH 條件）：

Propose mechanism for following Robinson Annulation reaction.

三階段機制：
  1. Michael addition：環酮 enolate 攻擊 α,β-不飽和酮的 β-碳（1,4-加成）→ 得 1,5-二酮
  2. 分子內 Aldol：另一端 α-H 被拔，enolate 攻擊另一羰基 → β-hydroxy ketone
  3. 脫水（Aldol condensation）：E1cb 脫水 → α,β-不飽和環酮（六員環為主）
考點：Michael donor 是 穩定 enolate（如 β-酮酯或環己酮），Michael acceptor 是 α,β-不飽和羰基。

7-5. Wittig 反應（111 重點題）

111 Q15 Wittig 機制 + Phosphorus Ylide 解釋（10 pts）111

寫出下列 Wittig 反應機制並解釋什麼是磷葉立德。

Propose a mechanism for the following Wittig reaction and explain what Phosphorus Ylide is.

(1) Phosphorus Ylide 定義：碳上有 負電孤對、磷上有 正電的雙性離子（R₃P⁺-CR'₂⁻ ↔ R₃P=CR'₂），由 R₃P + RCH₂X → 磷鹽 → 用強鹼（n-BuLi、NaH）拔 α-H 製得。
(2) Wittig 機制：
  1. Ylide 的 C⁻ 攻擊酮羰基 C → 形成 betaine（兩個電荷）
  2. O⁻ 攻擊 P⁺ → 四員環 oxaphosphetane
  3. 環逆向 [2+2] 分解 → 釋出 Ph₃P=O + alkene
位置選擇性：穩定化葉立德（如 Ph₃P=CHCO₂R）給 E-烯；非穩定葉立德（如 Ph₃P=CHR）給 Z-烯。

7-6. 1,3-Dithiane 形成（111 Q7）

111 Q7 機制：醛 + dithiol → 1,3-dithiane（6 pts）111

寫出機制（aldehyde + HS-CH₂CH₂-SH / H⁺ → cyclic dithioacetal）。

Propose a mechanism to account for the following transformation.

機制：類似 acetal 形成，但 S 取代 O：
  1. 酸質子化 C=O → C=OH⁺
  2. HS- 攻擊 C → hemithioacetal
  3. OH₂⁺ 離去 → thiocarbenium
  4. 第二個 HS- 攻擊 → 環狀 1,3-dithiane（含 -CHR- 連結兩個 S）
考點：dithioacetal 可以用 Raney Ni 還原為 -CH₂-，達成 C=O → CH₂ 的另一種方法（與 Clemmensen / Wolff-Kishner 並列）。

7-7. Lactam 形成（DCC 偶合）

107 Q10 機制：6-aminohexanoic acid + DCC → lactam（8 pts）107

寫出產物結構與反應機制。

Treatment of 6-aminohexanoic acid with DCC yield lactam. Show the structure of product and reaction mechanism.

機制：
  1. -COOH 質子轉移到 DCC 的 N，C 上 O 攻擊 DCC 的 C=N，形成 O-acyl isourea（活化羧酸）
  2. 分子內 -NH₂ 攻擊 acyl C → 四面體中間體
  3. 離去 dicyclohexylurea (DCU) → 七員環 caprolactam

7-8. Aldol 機制（111 Q10）

111 Q10 機制：分子內 Aldol（6 pts）111

7-9. Aspirin 合成（酸度分析）

111 Q13 Aspirin 合成（6 pts）111

水楊酸（salicylic acid）製備 Aspirin 的過程中，回答：(a) 水楊酸的哪個 H 最酸？(b) 預測產物 A 或 B 是主產物？(c) 為什麼主產物是它？

The process of preparing Aspirin is carried out from the salicylic acid starting material. (a) Which hydrogen of salicylic acid is the most acidic? (b) Please predict which of A or B is the main product. (c) WHY for major product.

答：
  • (a) 羧酸 H（-COOH）最酸（pKa ≈ 3-4）；酚 H（-OH）次之（pKa ≈ 10）。原因：羧酸根 -COO⁻ 共振穩定電荷分布於兩個 O。
  • (b) 主產物為 A（乙醯化在 -OH，得 acetylsalicylic acid，即 Aspirin）。
  • (c) NaOEt 先拔羧酸 H 形成 -COO⁻，再拔酚 -OH 變 -O⁻。酚氧負離子比羧酸氧負離子更具親核性（羧酸 -O⁻ 因共振電荷分散，親核性減弱），所以酚 -O⁻ 攻擊 acetic anhydride 的 C=O → 產物 A。

§9 推未知物 A~D（111 Q16）

Identify the structures of compounds A~D, as following.

§10 由苯合成目標分子（107 Q7）
107 Q7 從苯合成芳醛 / 芳基醯胺 / 芳酸（10 pts）107

從苯出發合成目標分子（含對位羧酸與醯胺），寫出每步驟試劑。

常用路徑（拼裝積木）：
  1. 苯 → 對位雙取代：依需要先做 acylation（產生 m-director）還是 alkylation（產生 o,p-director）。
