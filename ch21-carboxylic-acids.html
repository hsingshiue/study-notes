Chapter 21 — Carboxylic Acids and Their Derivatives

羧酸與其衍生物 ｜ 取代反應為主 ｜ 期末考重點
本章核心：羰基取代反應（acyl substitution）。羧酸衍生物（醯氯、酸酐、酯、醯胺、腈）都有 離去基，所以反應停在「取代」而不是「加成」 — 這是跟 Ch 20 醛酮（只能加成）最大的差別。
反應性順序必背：醯氯 > 酸酐 > 酯 > 醯胺（耐酸鹼程度則反過來）。
21.1-2 Introduction & Nomenclature 介紹與命名

羧酸基本結構

  • 羧酸 R-COOH（=羰基 C=O + 羥基 -OH 接在同一個 C 上）
  • 羧酸是所有羰基官能基中優先級最高的，所以命名時一定當主鏈後綴

★ 官能基優先序（從高到低）

21.3 Structure & Acidity 結構與酸性

物理性質

  • 沸點高：因 -COOH 可以形成雙重氫鍵（兩個分子互相 -O-H...O=C-）→ acetic acid (118°C) > isopropanol (82°C)
  • 水溶性：低分子量羧酸（C1-C4）完全溶於水

酸性

羧酸 pKa ≈ 4-5（中等強酸，比醇 pKa ≈ 16 強很多）。原因：羧酸根（carboxylate, R-COO⁻）被兩個 O 共振穩定（負電平均分散在 2 個 O 上）。

分子pKa
HCOOH（formic acid）3.75
CH₃COOH（acetic acid）4.76
CH₃CH₂COOH（propionic）4.87
PhCOOH（benzoic acid）4.19

★ 影響酸性的兩大因素

① 電子吸引基（EWG）使羧酸更酸（pKa 降）

21.7 ★ Reactivity of Acid Derivatives 衍生物反應性（核心）

★ 反應性大小（必背）

Acid chloride > Anhydride > (Thioester) > Ester > Amide
[最反應]　　　　　　　　　　　　　　　　　　　[最穩定]

反應性決定於：離去基的好壞（離去基越好越反應）+ 羰基的活化程度（共振 / 誘導）。

衍生物離去基離去基質量共振穩定 C=O
Acid chlorideCl⁻好（弱鹼）差（O lone pair 大，Cl 小）
AnhydrideRCOO⁻（carboxylate）中中
EsterRO⁻（alkoxide）差中等共振
AmideR₂N⁻（amide ion）很差（強鹼）強（N lone pair 進 π 系統，C-N 部分雙鍵性）

★ 取代反應的關鍵：為何醛酮無法取代，衍生物可以？

醛酮（Ch 20）：親核劑攻擊 C=O → 四面體中間體 → 無離去基（H 或 R 不會走）→ 反應停在加成，質子化得到醇。
羧酸衍生物（Ch 21）：親核劑攻擊 C=O → 四面體中間體 → 離去基（Z = Cl, OR, NHR...）跑掉 → C=O 重新形成 → 取代產物（addition-elimination）。

互轉規則

只能「向下」轉換（高反應性 → 低反應性）：
acid chloride → anhydride → ester → amide ✓（可以）
amide → ester → anhydride → acid chloride ✗（不行）
原因：低反應性衍生物已經很穩定，不會跑去變高能量的高反應性衍生物。
21.8 Acid Chlorides 醯氯（最反應）

製備

羧酸 + SOCl₂（thionyl chloride）→ acid chloride + SO₂ + HCl

機制：
  1. -COOH 的 O 攻擊 SOCl₂ 的 S → 形成 R-CO-O-S(Cl)=O 中間體（O 變成好離去基）
  2. Cl⁻ 攻擊羰基 C → 四面體中間體
  3. O-SO-Cl 離開（分解成 SO₂ + Cl⁻）→ 重建 C=O
  4. 得到 R-CO-Cl + SO₂ + HCl

反應（acid chloride 可以變身成所有其他衍生物）

試劑產物
H₂O / pyridine羧酸（hydrolysis）
R'OH / pyridineEster
RCOO⁻（carboxylate）Acid anhydride
過量 NH₃1° amide（-CONH₂）
過量 RNH₂N-取代 amide
過量 R₂NHN,N-取代 amide
1) LAH 過量　2) H₂O1° alcohol
1) LiAl(OR)₃H 2) H₂O
（tri-tert-butoxyaluminum hydride）		Aldehyde（停在醛！）
1) RMgBr 過量　2) H₂O3° alcohol
R₂CuLi（Gilman reagent）Ketone（停在酮！）
為什麼需要 pyridine？反應放出 HCl，會把胺類質子化失活，或讓反應混合物變酸。Pyridine 是中和 HCl 的鹼，保持反應正常。
為什麼用胺類要 2 當量？第 1 當量胺攻擊變產物 + HCl；第 2 當量胺中和 HCl（不然會變回去）。
★ 兩個「半還原」試劑（停在醛/酮，不會繼續還原）：
① LiAl(O-tBu)₃H：把 acid chloride 還原成 aldehyde（不會變醇）
② Gilman (R₂CuLi)：把 acid chloride 攻擊變成 ketone（不像 Grignard 會繼續攻擊）
21.9 Acid Anhydrides 酸酐

製備

  • 工業：2 acetic acid 800°C → acetic anhydride + H₂O
  • 實驗室：1) 羧酸 + NaOH → carboxylate 2) + acid chloride → anhydride

反應（跟 acid chloride 類似，但反應慢一點；離去基是 carboxylate）

典型反應：aspirin 跟 Tylenol 的合成

  • Aspirin（乙醯水楊酸）：水楊酸（含 -OH 和 -COOH）+ acetic anhydride → 酚 -OH 被乙醯化
  • Tylenol（acetaminophen）：4-aminophenol + acetic anhydride → -NH₂ 被乙醯化（變 amide）
21.10 Preparation of Esters: Fischer Esterification 費雪酯化
Fischer esterification：羧酸 + 醇 + H⁺ 催化 ⇌ 酯 + H₂O
可逆反應，用 Le Chatelier 控制方向。
機制（6 步）：PADPED
  1. Protonation：H⁺ 質子化 C=O 的 O → 增加 C 親電性
  2. Addition：醇攻擊質子化羰基 C → 四面體中間體（O⁺ 在 R-O-H）
  3. Deprotonation：去質子化新接的 O → 中性四面體
  4. Protonation：質子化原本 -OH 的 O → 變 -OH₂⁺（好離去基）
  5. Elimination：H₂O 離開 → 重建 C=O（變 ester）
  6. Deprotonation：失質子 → 得中性 ester

用 Le Chatelier 控制方向

目標策略
要得到 ester（正向）① 加過量醇 ② 移除水（Dean-Stark trap）
要水解 ester 回 acid（逆向）加大量水 + H⁺ 加熱
21.11 Reactions of Esters 酯的反應

★ Saponification（皂化 = 鹼性水解）

Ester + NaOH / H₂O（過量）→ 羧酸鈉（carboxylate）+ alcohol

機制：
  1. HO⁻ 攻擊 C=O 碳 → 四面體 alkoxide 中間體
  2. R-O⁻（alkoxide）離開 → 重建 C=O（變羧酸）
  3. 羧酸馬上被 NaOH 去質子化 → carboxylate（很穩定）
  4. 反應變不可逆（因為 carboxylate 不會再被親核攻擊）
要得到中性羧酸：最後加 H₃O⁺ 酸化把 carboxylate 變回 -COOH。
Saponification 字源：sapo = 拉丁文「肥皂」。古代用脂肪（三酯）+ NaOH 水解 → 脂肪酸鈉鹽（= 肥皂）+ 甘油。

★ 還原 ester 的兩種試劑

試劑產物說明
1) 過量 LAH　2) H₂O1° alcohol + R'OH完全還原（兩次 H⁻ 攻擊）
1) DIBAH（di-iso-butyl aluminum hydride）　2) H₂OAldehyde + R'OH停在醛！溫和選擇還原

Ester + Grignard

Ester + 2 RMgX → 3° alcohol（兩次 R 攻擊，先得 ketone 中間體，再被第 2 個 R 攻擊）

Ester + NH₃ → Amide

Ester + 過量 NH₃ → amide + R'OH（acid → ester → amide 的「向下」轉換）

21.12 Amides 醯胺（最穩定）

製備（從更高反應性的衍生物）

  • Acid chloride + 過量胺（NH₃ / RNH₂ / R₂NH）→ amide
  • Anhydride + 胺 → amide
  • Ester + 過量 NH₃ → amide

水解（很慢，需要強條件）

條件產物速度
H₃O⁺ / 高溫羧酸 + NH₄⁺慢
NaOH / H₂OCarboxylate + 胺很慢
為何 amide 反應這麼慢？N 的 lone pair 強烈共振進 C=O → C-N 有部分雙鍵性 → 反應性最低。這也是為什麼蛋白質（含醯胺鍵）很穩定，能在生物體內存在。

LAH 還原 amide → amine

R-CO-NR'₂ + LAH → R-CH₂-NR'₂（醯胺被還原成胺，不是醇，因為 N 也跟著被「帶走」）

機制：
  1. H⁻ 攻擊 C=O → 四面體中間體
  2. O⁻ 跑掉（不是 NR₂⁻，因為 NR₂⁻ 太差的離去基），但因為 N 有共振 → 形成 iminium ion（C=N⁺）
  3. 第二個 H⁻ 攻擊 iminium 的 C → 變 amine

★ Nylon = 聚醯胺（polyamide）

工業合成兩種 Nylon：

類型原料
Nylon 6,6己二酸（adipic acid）+ 1,6-diaminohexane（hexamethylenediamine）→ 大量 amide 鍵相連
Nylon 6ε-caprolactam（7 員環 lactam）開環聚合

Polyester（聚酯）類似但用 diol + diacid，鍵結為 ester 而不是 amide。

21.13 Nitriles 腈

R-C≡N 雖然沒 C=O，但 C 的氧化態跟羧酸一樣 → 算羧酸衍生物。

製備

反應條件
1° 或 2° 烷基鹵化物 + NaCNSN2 取代
1° amide 脫水SOCl₂（或 P₂O₅）

水解

條件產物
H₃O⁺ / heat羧酸 + NH₄⁺
（先變 amide 再變 acid）
1) NaOH / H₂O　2) H₃O⁺羧酸 + NH₃

★ Nitrile + Grignard → Ketone（用 nitrile 合成酮的方法）

  1. R-C≡N + R'MgX → R-C(R')=NMgX（imine 中間體）
  2. + H₃O⁺（少量水）→ R-CO-R'（ketone）+ NH₃
合成價值：「R-X → R-CN → R-CO-R'」是把烷基鹵化物變酮的途徑（增加碳鏈）。

Nitrile + LAH → 1° amine

R-C≡N + 過量 LAH → R-CH₂-NH₂（兩次 H⁻ 攻擊三鍵）

Ex. 範例題 Practice Problems
範例 1 — pKa 排序 / Acidity Ranking
把下列分子按 pKa 由小到大（最酸 → 最不酸）排序：A. CH₃CH₂COOH（丙酸）　B. CH₃COOH（乙酸）　C. CH₃CH₂COSH（硫代乙酸）　D. (CH₃)₂CH-CO-CH₂OH（β-羥基甲酮）
Rank the following molecules by increasing pKa (most acidic first): A. propanoic acid　B. acetic acid　C. thiopropanoic acid (RCOSH)　D. β-hydroxy ketone (only has alcohol -OH)
答案：C < B < A < D
‧ C（thioacid R-CO-SH，pKa ≈ 3）：硫的負電比氧穩定（S 較大），是最酸
‧ B（acetic acid，pKa = 4.76）：羧酸
‧ A（propionic acid，pKa = 4.87）：多一個 CH₃ 推電子，比 acetic acid 略弱
‧ D（只有 -OH，pKa ≈ 16）：一般醇，最不酸
範例 2 — 預測產物 / Predict the Product
acetic anhydride + 4-aminophenol → 主產物為何？這是什麼藥的合成？
What is the major product when acetic anhydride reacts with 4-aminophenol? What pharmaceutical does this make?
答案：
主產物：N-(4-hydroxyphenyl)acetamide（4-羥基苯基乙醯胺）= Tylenol / acetaminophen（普拿疼）
胺（-NH₂）比酚（-OH）更親核 → -NH₂ 先被乙醯化變 amide。產物 -OH 保留不動。
範例 3 — 命名 / IUPAC Name
為下列化合物寫出系統命名：
① CH₃CH₂CH₂COOCH₃　② (CH₃)₂CHCONH₂　③ HOOC-CH₂-CH₂-COOH
Provide IUPAC names for:
① CH₃CH₂CH₂COOCH₃　② (CH₃)₂CHCONH₂　③ HOOC-CH₂-CH₂-COOH
① methyl butanoate（甲基丁酸酯）
② 2-methylpropanamide（2-甲基丙醯胺）
③ butanedioic acid（丁二酸 / succinic acid）
範例 4 — 選擇試劑 / Choose Reagent
想把 acid chloride 還原成醛（不是醇），用什麼試劑？想還原成酮（加一個 R），用什麼？
Which reagent reduces acid chloride to aldehyde (not alcohol)? Which gives a ketone (adds one R group)?
到醛：LiAl(O-tBu)₃H（tri-tert-butoxyaluminum hydride）。tBu 體積大，只送 1 個 H⁻，所以停在 aldehyde。
到酮：R₂CuLi（Gilman reagent）。Gilman 跟酸氯反應後產物是 ketone（Gilman 不會再攻擊 ketone）。
範例 5 — 合成路徑 / Synthesis
如何從 benzyl bromide（PhCH₂Br）合成 phenylacetic acid（PhCH₂COOH）？給兩種方法。
How would you synthesize phenylacetic acid (PhCH₂COOH) from benzyl bromide (PhCH₂Br)? Give two methods.
方法 1（NaCN 路線）：
PhCH₂Br + NaCN → PhCH₂CN（SN2）
PhCH₂CN + H₃O⁺/heat → PhCH₂COOH

方法 2（Grignard + CO₂ 路線）：
PhCH₂Br + Mg/ether → PhCH₂MgBr
+ CO₂ → PhCH₂COO⁻MgBr⁺
+ H₃O⁺ → PhCH₂COOH

兩條路線都增加一個碳（PhCH₂Br 有 7 C，產物有 8 C）。
範例 6 — 機制 / Mechanism
為什麼用 acid chloride 跟胺類反應做 amide 時，需要 2 當量 的胺？
Why are 2 equivalents of amine needed when synthesizing an amide from an acid chloride?
答案：反應放出 HCl。
‧ 第 1 當量胺：攻擊 acid chloride 變 amide（同時放出 HCl）
‧ 第 2 當量胺：扮演鹼角色，中和 HCl（變 R-NH₃⁺ Cl⁻），避免 HCl 把胺質子化失活，或讓反應逆轉。
替代方案：用 pyridine 當鹼，就只需 1 當量胺。

反應性順序（必背）

  • 反應性：醯氯 > 酸酐 > 酯 > 醯胺
  • 穩定性：相反順序
  • 互轉：只能向下（高反應性 → 低反應性）

命名速記

  • 羧酸：-oic acid、環+羧酸：-carboxylic acid
  • 醯氯：-oyl chloride（八大例外字根記住）
  • 酸酐：-anhydride，不對稱按字母順序
  • 酯：R'基 + 酸名-ate，中間空格
  • 醯胺：-amide，N 上有取代基寫 N-...
  • 腈：-onitrile

影響酸性

  • EWG（NO₂、Cl、F）→ 更酸（pKa 小）
  • 距離越近（α）影響越大
  • 苯甲酸 para-取代：EWG → 更酸；EDG → 較不酸

關鍵反應

  • SOCl₂：酸 → 醯氯
  • Fischer esterification：酸 + 醇 / H⁺（可逆）
  • Saponification：酯 + NaOH → 羧酸鈉 + 醇（不可逆）
  • Acid chloride + 2 NH₃ → amide + NH₄Cl
  • Acid chloride + 過量 LAH → 1° alcohol；+ LiAl(OtBu)₃H → aldehyde；+ R₂CuLi → ketone
  • Ester + DIBAH → aldehyde（停在中間）
  • Amide + LAH → amine（不是醇！）
  • Nitrile + LAH → 1° amine；+ RMgX/H₃O⁺ → ketone；+ H₃O⁺/heat → 羧酸

合成關鍵：增加 C 的方法

  • R-X + NaCN → R-CN（+1 C）
  • R-X + Mg → R-MgX + CO₂ → R-COOH（+1 C）
  • R-CN + R'MgX/H₃O⁺ → R-CO-R'（+1 C 變酮）
跟 Ch 20 對照記憶：
Ch 20（醛酮）：C=O 沒離去基 → 反應停在加成，得到醇 / imine / acetal 等
Ch 21（羧酸衍生物）：C=O 有離去基 → 反應走取代（addition-elimination），衍生物互轉
兩章的機制起頭一樣（親核劑攻擊 C=O 形成四面體中間體），後續走向不同。
